# Four-day plan (30 focused hours)

1. **Day 1 — Foundation (8 h):** Requirements, schema and constraints, PostgreSQL, migrations, exact recipes, password/session authentication and first Git milestone. Prepare cloud configuration locally.
2. **Day 2 — Cutting (7 h):** Authenticated demo panel, cutting dashboard, creation and corrections, immediate expected components, server validation, persistence and submission.
3. **Day 3 — Verification (8 h):** Count persistence, traffic lights, transactional decisions, immutable snapshots, rejection/resubmission, concurrency and role tests.
4. **Day 4 — Handoff and delivery (7 h):** Verified-only sewing queue, assembly action, mandatory and adversarial HTTP integration tests, responsive/contrast browser review, production build, README/AI report and publishing handoff.

These are planned work blocks, not a claim of elapsed development days. Commits record actual completed milestones.
